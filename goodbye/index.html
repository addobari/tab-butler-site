One question, if you have a moment: what made you remove Simmer?

Pick the closest answer. It opens an email to me, Addo, with the answer filled in. Add a line if you like, or just send it.

  • It closed or hid tabs I wanted open
  • It didn't find what I was working on
  • It slowed Chrome down or used too much memory
  • I couldn't work out how to use it
  • I was only trying it out
  • Something else

This page knows nothing about you, and nothing was sent to get you here. Only an email you choose to send reaches me.

Removed it by mistake?

You can add Simmer again from the Chrome Web Store. What was on the back burner went with the old copy, unless you saved a backup from Settings → Data.
