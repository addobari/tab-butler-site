Turn a list of links into Chrome bookmarks

Paste links or a OneTab export and download a bookmarks file Chrome can import, sorted into a folder per site, or copy them as Markdown. Nothing leaves your browser.

Paste links to begin.

Runs in this page. What you paste isn't sent anywhere or saved.

Short answer

Paste your links or a OneTab export, choose how to sort them, and press Download. You get a bookmarks file. In Chrome, open the bookmark manager (Ctrl+Shift+O, or ⌘+Option+B on a Mac), open its ⋮ menu, choose Import bookmarks and pick the file. The links arrive in a folder, sorted the way you chose.

What you can paste

  • A plain list, one link per line.
  • A OneTab export. In OneTab, choose Export / Import URLs and copy the list. Each line is a link and its title, and the titles are kept.
  • Any text with links in it, such as an email or a document. Only the links are kept.

Import the file into Chrome

  1. Open the bookmark manager. Press Ctrl+Shift+O (⌘+Option+B on a Mac).
  2. Choose Import bookmarks. It's in the ⋮ menu at the top right of the bookmark manager.
  3. Pick the file. It's called bookmarks-simmer.html, in your Downloads folder. The links arrive in a folder you can move anywhere.

The file is the standard bookmarks format, so Edge, Firefox and Safari import it too.

Markdown and plain lists

Copy as Markdown gives you a heading for each folder and a list of titled links, ready for notes apps, documents and README files. Copy as a plain list gives one link per line, ready to paste into Open many links at once.

Tabs that stay together without filing

Bookmark folders work when you remember to file them. Simmer, our free Chrome extension, does the filing for you: it sorts your open tabs into the things you're in the middle of, puts a whole task away when you're done for now, and brings every tab back in one click, in its group. It can save what it puts away to your bookmarks as well.

Questions

How do I import a bookmarks file into Chrome?
Open the bookmark manager with Ctrl+Shift+O (⌘+Option+B on a Mac), open its ⋮ menu, choose Import bookmarks and pick the file. The bookmarks arrive in a folder.
How do I move my OneTab list into Chrome bookmarks?
In OneTab choose Export / Import URLs, copy the list, paste it here with Sort into set to A folder for each group, and download the file. Then import it in Chrome's bookmark manager.
Will this change my existing bookmarks?
No. Importing adds a new folder; nothing already in your bookmarks is changed or removed.
Does this tool upload my links?
No. It runs in the page, in your browser. The file is made on your computer, and the page has no trackers.
